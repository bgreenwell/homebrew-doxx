# Homebrew tap for doxx

This is the official Homebrew tap for [doxx](https://github.com/bgreenwell/doxx) - a terminal document viewer for .docx files.

## Installation

```bash
# Add the tap and install
brew tap bgreenwell/doxx
brew install doxx

# Or install directly in one command
brew install bgreenwell/doxx/doxx
```

## About doxx

doxx is a fast, terminal-native document viewer for Microsoft Word files. View, search, and export `.docx` documents without leaving your command line.

### Key features
- Beautiful terminal rendering with formatting, tables, and lists
- Fast search with highlighting
- Multiple export formats (Markdown, CSV, JSON, plain text)
- Terminal image support for modern terminals
- Cross-platform support (macOS, Linux, Windows)
